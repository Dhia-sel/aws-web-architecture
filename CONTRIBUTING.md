# Contributing

**[English](#english) | [Français](#français)**

---

## English

This repository is an academic capstone project and is not currently open 
for external contributions. It is shared publicly for documentation and 
portfolio purposes.

If you have suggestions or spot an issue in the architecture or 
documentation, feel free to open an Issue — feedback is welcome even though 
active contributions are not being accepted at this time.

---

## Français

Ce dépôt est un projet académique de fin de cours et n'est pas ouvert aux 
contributions externes pour le moment. Il est publié publiquement à des 
fins de documentation et de portfolio.

Si vous avez des suggestions ou remarquez un problème dans l'architecture 
ou la documentation, n'hésitez pas à ouvrir une Issue — les retours sont 
les bienvenus même si les contributions actives ne sont pas acceptées 
actuellement.
